## 1. Problem Anchor（问题锚点）

**场景**：多UAV协同搜索-攻击任务规划（Cooperative Search-Attack Mission Planning, CSAMP）。在100×100 km网格战场中，10架UAV需要协同完成对5个目标的搜索与摧毁，同时规避7个已知/未知威胁区域。

**核心挑战**：
- **组合爆炸**：10个UAV × 10000个网格 × 多步决策，传统精确求解不可行
- **部分可观测**：每架UAV仅能感知局部区域（搜索半径3km），需要通过通信共享信息
- **异构任务耦合**：搜索（exploration）与攻击（exploitation）两种模式需要动态切换
- **实时性要求**：UAV速度100m/s，决策频率需达到1Hz以上

**应用价值**：该问题直接对应军事领域的SEAD（Suppression of Enemy Air Defenses）任务，也可推广到灾害搜救、环境监测等民用场景。

## 2. Technical Gap（技术差距）

| 现有方法 | 局限性 |
|---------|--------|
| 蚁群优化（ACO） | 收敛慢，难以处理动态环境，无法实时决策 |
| 遗传算法（GA） | 离线规划，不适应环境变化 |
| 单智能体DRL | 无法扩展到10+UAV，缺乏协同机制 |
| 传统MADRL（Independent Q-Learning） | 环境非平稳，训练不稳定 |
| 基于规则的协同 | 人工设计规则难以覆盖所有场景 |

**关键Gap**：现有方法缺乏一种能够同时处理 **动态拓扑通信**、**异构任务分配** 和 **实时决策** 的统一框架。

## 3. Method Thesis（方法论点）

> **核心论点**：通过Graph Attention Network建模UAV间动态通信拓扑，结合分层Multi-Agent策略（高层模式选择 + 低层动作执行），在MAPPO框架下实现端到端的协同搜索-攻击任务规划。

**方法名称**：MADRL-GAT（Multi-Agent Deep Reinforcement Learning with Graph Attention Network）

## 4. 详细方法设计

### 4.1 环境建模

```
战场参数：
- 网格大小：100 × 100（每格1km × 1km）
- UAV数量：N = 10
- 目标数量：M = 5（初始位置未知，需搜索发现）
- 威胁区域：K = 7（3个已知 + 4个未知）
- UAV速度：v = 100 m/s（每时间步移动1格）
- 搜索半径：R_s = 3km（3格）
- 攻击半径：R_a = 1km（1格）
- 弹药量：每架UAV携带2枚
- 最大时间步：T_max = 500
```

### 4.2 观测空间设计

每架UAV i 的观测 o_i 由三部分组成：

**（1）局部网格观测** — 11×11 patch（以自身为中心）
- 通道1：地形/障碍信息（0/1）
- 通道2：已探索区域标记（0/1）
- 通道3：已知威胁区域热力图（0~1，距离衰减）
- 通道4：已发现目标位置（0/1）
- 通道5：友方UAV位置（0/1）

局部观测张量维度：`[5, 11, 11] = 605`

**（2）自身状态向量**
```
s_i = [x_i, y_i,           # 归一化位置 (2)
       ammo_i,              # 剩余弹药 (1)
       mode_i,              # 当前模式: 0=搜索, 1=攻击 (1)
       fuel_i,              # 剩余燃料比例 (1)
       step_t / T_max]      # 时间进度 (1)
```
维度：6

**（3）GAT聚合的邻居信息**
- 通过2层GAT聚合通信范围内邻居的嵌入
- 输出维度：64

**总观测维度**：605 + 6 + 64 = 675

### 4.3 动作空间设计

采用分层动作空间：

**高层动作（模式选择）**：
- `mode ∈ {SEARCH, ATTACK}` — 2个离散选项

**低层动作（运动+执行）**：
- 搜索模式：8方向移动 + 停留 = 9个动作
- 攻击模式：8方向移动 + 停留 + 攻击最近目标 = 10个动作

**联合动作空间大小**：2 × 10 = 20（取最大值统一编码）

### 4.4 GAT通信模块

```
GAT架构：
- 层数：2层
- 隐藏维度：64
- 注意力头数：4（每头16维）
- 激活函数：ELU
- Dropout：0.1
- 邻居定义：通信范围内的UAV（待明确具体距离）
```

**输入**：每架UAV的局部嵌入 h_i（由局部观测经CNN编码得到）
**处理流程**：
1. 第1层GAT：聚合1-hop邻居信息
2. 第2层GAT：聚合2-hop邻居信息（扩大感知范围）
3. 输出：每架UAV的全局感知嵌入 z_i ∈ R^64

**注意力计算**：
```
α_ij = softmax_j(LeakyReLU(a^T [W h_i || W h_j]))
z_i = σ(Σ_j α_ij W h_j)
```

### 4.5 策略网络架构

```
观测编码器（每架UAV共享参数）：
├── CNN分支（处理11×11局部网格）
│   ├── Conv2d(5, 32, 3, padding=1) + ReLU
│   ├── Conv2d(32, 64, 3, padding=1) + ReLU
│   ├── MaxPool2d(2)
│   └── Flatten → Linear(64*5*5, 128) → ReLU
├── MLP分支（处理自身状态）
│   └── Linear(6, 32) → ReLU → Linear(32, 64) → ReLU
└── 拼接 → Linear(128+64, 128) → ReLU → h_i

GAT通信层：
├── h_i → GAT_Layer1(128→64, 4heads) → ELU
└── → GAT_Layer2(64→64, 4heads) → ELU → z_i

策略头（Actor）：
├── Linear(128+64, 128) → ReLU  # 拼接 h_i 和 z_i
├── Linear(128, 64) → ReLU
└── Linear(64, 20) → Softmax → π(a|o)

价值头（Critic）：
├── 输入：所有UAV的 z_i 拼接（全局状态）
├── Linear(64*10, 256) → ReLU
├── Linear(256, 128) → ReLU
└── Linear(128, 1) → V(s)
```

### 4.6 奖励函数设计

```python
def compute_reward(env_state, action, agent_id):
    reward = 0.0
    
    # 搜索奖励
    new_cells = count_newly_explored_cells(agent_id)
    reward += 0.5 * new_cells          # 搜索覆盖增量
    
    # 目标相关奖励
    if discovered_new_target(agent_id):
        reward += 5.0                   # 发现新目标
    if destroyed_target(agent_id):
        reward += 10.0                  # 摧毁目标
    
    # 惩罚
    if in_threat_zone(agent_id):
        reward -= 3.0                   # 进入威胁区
    reward -= 0.01                      # 时间步惩罚（鼓励效率）
    
    # 协同奖励
    if cooperative_attack(agent_id):    # 多UAV协同攻击同一目标
        reward += 3.0
    
    return reward
```

### 4.7 训练方案

**算法**：MAPPO（Multi-Agent Proximal Policy Optimization）

```
训练超参数：
- 学习率：lr = 3e-4（Adam优化器）
- 折扣因子：γ = 0.99
- GAE参数：λ = 0.95
- PPO clip参数：ε = 0.2
- Entropy系数：0.01
- Value loss系数：0.5
- 最大梯度范数：0.5
- Mini-batch大小：64
- 并行环境数：16
- 每次更新的epoch数：10
- Rollout长度：128步
```

### 4.8 课程学习策略

**3阶段课程**：

| 阶段 | 环境设置 | 训练步数 | 目标 |
|------|---------|---------|------|
| Stage 1 | 3 UAV, 2目标, 0威胁, 50×50网格 | 2M steps | 学习基本搜索和攻击 |
| Stage 2 | 6 UAV, 3目标, 3威胁, 75×75网格 | 3M steps | 学习协同和威胁规避 |
| Stage 3 | 10 UAV, 5目标, 7威胁, 100×100网格 | 5M steps | 完整任务 |

**预计训练时间**：~4小时（单张A100 GPU）

### 4.9 评估指标

| 指标 | 定义 | 目标 |
|------|------|------|
| 搜索覆盖率 | 已探索格子数 / 总格子数 | > 85% |
| 目标摧毁率 | 摧毁目标数 / 总目标数 | > 90% |
| 平均任务完成时间 | 摧毁所有目标的平均步数 | < 300步 |
| UAV存活率 | 存活UAV数 / 总UAV数 | > 80% |
| 协同攻击比例 | 协同攻击次数 / 总攻击次数 | > 50% |

## 5. 与蚁群优化的对比优势

| 维度 | ACO | MADRL-GAT（本方案） |
|------|-----|-------------------|
| 决策速度 | 需要多次迭代（秒级） | 单次前向推理（毫秒级） |
| 动态适应 | 需要重新规划 | 实时响应环境变化 |
| 协同机制 | 信息素间接通信 | GAT显式通信+注意力 |
| 可扩展性 | 随UAV数指数增长 | 参数共享，线性扩展 |
| 任务耦合 | 搜索攻击分离处理 | 端到端联合优化 |
