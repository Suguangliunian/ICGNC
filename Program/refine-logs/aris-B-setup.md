# 阶段B准备：TAGA-MAPPO → Qwen3.5-4B LLM 融合方案

> 日期: 2026-04-08
> 基础: 阶段A最终方案(TAGA-MAPPO, 9.0/10) + 已有Qwen方案(8.9/10)

---

## 1. 融合策略

阶段A的核心创新是TAGA（动态拓扑自适应注意力），阶段B需要将这个创新点与Qwen3.5-4B大模型融合。

**关键思路**: 用LLM替代MAPPO策略网络，但保留TAGA的核心思想——将动态通信拓扑信息编码到LLM的输入prompt中。

| 阶段A组件 | 阶段B对应 |
|-----------|----------|
| TAGA注意力机制 | Prompt中的拓扑感知邻居信息编码 |
| 分层策略网络 | LLM的CoT推理（先思考模式，再决定动作） |
| MAPPO训练 | LoRA微调（SFT on expert trajectories） |
| 课程学习 | 多场景配置的训练数据 |
| 奖励函数 | 专家轨迹筛选标准 |

**核心创新点转化**:
- TAGA的距离衰减 → Prompt中按距离排序邻居，近邻信息更详细
- TAGA的任务感知 → Prompt中标注邻居的任务模式
- TAGA的信息新鲜度 → Prompt中标注信息更新时间

## 2. 基线方案

以已有的 `qwen-round-5-refinement.md` 为起点（8.9/10），融入阶段A的TAGA思想。

## 3. ARIS-B评估维度

与阶段A相同的7维度，但增加LLM特有的关注点：
- Token效率（prompt长度 vs 信息密度）
- 推理延迟（实时决策约束）
- 训练数据质量（专家轨迹的代表性）
- LoRA表达能力（是否足够学习决策策略）
